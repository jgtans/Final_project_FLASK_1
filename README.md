# Блог на Flask

Веб-приложение блога с системой аутентификации, созданное на фреймворке Flask.

## Возможности

- ✅ Регистрация и вход пользователей
- ✅ Создание, редактирование и удаление постов
- ✅ Пагинация списка постов
- ✅ Защита маршрутов (только авторизованные пользователи)
- ✅ Проверка прав доступа (редактирование/удаление только своих постов)
- ✅ Адаптивный дизайн на Bootstrap 5
- ✅ Flash-сообщения для уведомлений
- ✅ Валидация форм

## Установка

### 1. Клонируйте репозиторий

```bash
git clone <url-репозитория>
cd <имя-папки>
```

### 2. Создайте виртуальное окружение

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения (опционально)

Создайте файл `.env` в корне проекта:

```env
SECRET_KEY=ваш-секретный-ключ
DATABASE_URL=sqlite:///app.db
```

> **Внимание:** `SECRET_KEY` должен быть уникальной случайной строкой для продакшена.

### 5. Инициализируйте базу данных

```bash
flask db init
flask db migrate -m "Initial migration"
flask db upgrade
```

Или просто запустите приложение — база данных SQLite будет создана автоматически при первом запуске.

### 6. Запустите приложение

```bash
python run.py
```

Приложение будет доступно по адресу: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## Использование

1. **Регистрация:** Перейдите на страницу регистрации и создайте учётную запись.
2. **Вход:** Войдите под своими учётными данными.
3. **Создание поста:** Нажмите «Создать пост» в навигационном меню.
4. **Просмотр:** Кликните на заголовок поста для просмотра полной версии.
5. **Редактирование/Удаление:** Доступно только автору поста.

## Технологии

- **Backend:** Python 3, Flask 3.0
- **База данных:** SQLite (по умолчанию), поддержка других СУБД через SQLAlchemy
- **ORM:** Flask-SQLAlchemy, Flask-Migrate
- **Аутентификация:** Flask-Login
- **Формы:** Flask-WTF, WTForms
- **Frontend:** Bootstrap 5, Jinja2

## Конфигурация

Основные настройки находятся в `config.py`:

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `SECRET_KEY` | Секретный ключ для сессий | `'dev-secret-key-change-me'` |
| `SQLALCHEMY_DATABASE_URI` | URL подключения к БД | `sqlite:///app.db` |
| `SQLALCHEMY_TRACK_MODIFICATIONS` | Отслеживание изменений моделей | `False` |

## Безопасность

- Пароли хранятся в хешированном виде (werkzeug.security)
- Валидация email и уникальности username/email
- Защита от CSRF-атак (Flask-WTF)
- Проверка прав доступа к операциям с постами
- Санитизация URL для редиректов после входа
